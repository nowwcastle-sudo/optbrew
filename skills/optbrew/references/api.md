# Collection and optional API boundary

The optbrew audit command is `node skills/optbrew/scripts/audit.mjs --context <run-context.json> --modules naver-searchadvisor,magnus-seo --output-dir <run-dir>`. It writes raw responses, `collection.json`, `modules.json`, `observations.json` and `evidence-index.json` under `<run-dir>/evidence/`. The evidence index binds the run ID, context reference, raw response hashes and module/observation paths for later scoring and reporting. Reusing an output directory with an existing collection index is rejected. The audit never posts to a search engine or changes the site.

`RunContext.scope.allowed` is a nonempty list of `{ "origin": "https://example.org", "path_prefix": "/owned/" }`. An origin fixes scheme, host and effective port. The path prefix is segment bounded. `scope.local_targets` may list explicit `{ "host": "localhost", "port": 8765 }` pairs for a declared local target. Without this pair, loopback, private, link-local, ULA and mapped IPv4 addresses are blocked. The default ceilings are 50 URLs, depth 3, concurrency 2, 20 seconds, 5 MiB and 10 redirects. Lower limits may be set with `max_urls`, `max_depth` and `concurrency`. Every redirect is checked against scope and fresh DNS; the Node transport connects to the vetted address and preserves TLS hostname verification. A host MCP or bulk crawler is selected only if it can guarantee the same boundary and cost controls.

For a paid Anthropic Messages call, `cost_decision` needs `approval_ref` and `providers.anthropic.upper_bounds`, such as `[{ "unit": "tokens", "amount": 2000 }, { "unit": "search_calls", "amount": 1 }]`. The ledger needs a matching approval reference and budgets with `{provider,unit,amount}`; `currency_minor` also requires an ISO 4217 currency code. Credits, tokens, search calls and minor currency units remain separate. The caller supplies a currently supported `model` and any web search tool declaration in the official Messages request body. Optbrew does not substitute a model or add a search tool. The direct adapter checks only whether `ANTHROPIC_API_KEY` exists, reserves an upper bound for each attempt, and tries at most twice for retryable HTTP errors. A timeout, malformed response or unmeasurable charge settles as `unknown`, retaining the reserved upper bound. Successful responses are redacted and stored beside the ledger under `evidence/provider/`. No decision, upper bound or key means no provider request. Host MCP billing that cannot be locked in this ledger must be labeled `enforcement=host_policy`.

Primary syntax checked 2026-10-14: [Anthropic Messages API](https://docs.anthropic.com/en/api/messages), [Anthropic web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool), [Node HTTPS request](https://nodejs.org/api/https.html#httpsrequesturl-options-callback), [Node DNS lookup](https://nodejs.org/api/dns.html#dnslookuphostname-options-callback). These describe API/CLI mechanics, not a price approval or evidence of an actual paid call.
