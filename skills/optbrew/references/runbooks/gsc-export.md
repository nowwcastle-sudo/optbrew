# Search Console 실적 데이터 내보내기

## beginner

이 절차는 Google Search Console용입니다. 이 서비스를 쓰지 않으면 이 절차는 건너뛰세요.

왜 필요한가: optbrew는 사이트를 밖에서 읽는 것만 할 수 있어서, 사이트가 Google 검색에서 실제로 몇 번 보이고 클릭됐는지는 모릅니다. 사이트 소유자만 보는 Search Console 데이터를 파일로 내려받아 주면 그 숫자를 감사 결과와 함께 볼 수 있습니다. 사이트가 Search Console에 등록되어 있고 내가 소유자(또는 권한이 있는 사용자)일 때만 합니다. 내 사이트가 아니면 건너뜁니다.

1. 브라우저에서 search.google.com/search-console을 엽니다.
2. 사이트 소유 권한이 있는 Google 계정으로 로그인합니다.
3. 왼쪽 위의 속성 선택 상자를 눌러 감사할 사이트를 고릅니다. 사이트가 목록에 없으면 이 계정에 권한이 없는 것이므로 여기서 멈춥니다.
4. 왼쪽 메뉴에서 **실적**(Performance) → **검색결과**(Search results)를 누릅니다. (화면 확인 필요: 한글 메뉴 이름)
5. 위쪽 날짜 선택(기본 최근 3개월)을 눌러 기간을 고릅니다. 가능하면 선택지 중 가장 긴 기간을 고르고 **적용**(Apply)을 누릅니다. (화면 확인 필요: 선택지와 버튼 이름)
6. 화면 오른쪽 위의 내보내기(Export) 버튼을 찾습니다. 아래쪽 화살표가 그려진 다운로드 아이콘입니다. (화면 확인 필요: 위치)
7. 버튼을 눌러 형식을 고릅니다. 엑셀 없이 쓰려면 **CSV 다운로드**(Download CSV)가 가장 단순합니다. (화면 확인 필요: 형식 이름)
8. 파일이 내려받아집니다. CSV는 여러 시트가 든 압축(.zip) 파일로 받아집니다. 압축을 풀지 않고 그대로 둡니다. 압축 안에는 쿼리, 페이지, 국가, 기기, 날짜 등이 따로 들어 있고, 적용한 필터를 적은 파일도 있습니다. (화면 확인 필요: 현재 구성)
9. 파일은 보통 브라우저의 기본 저장 폴더인 **다운로드**(Downloads) 폴더에 저장됩니다. 그 폴더에서 방금 받은 파일의 이름을 확인해, 폴더 이름과 파일 이름을 에이전트에게 알려 줍니다. 파일 내용은 대화에 붙이지 않습니다.
10. 알아둘 점: 화면에서 내려받는 데이터는 최대 1,000행입니다. 방문 많은 사이트는 일부만 담깁니다.

## brief

- Google Search Console용입니다. 이 서비스를 쓰지 않으면 이 절차는 건너뛰세요.
- search.google.com/search-console → 속성 선택 → **실적 → 검색결과**에서 기간을 정하고 내보내기 아이콘으로 Google Sheets·Excel·CSV 중 하나를 받습니다. (한글 이름은 화면 확인 필요)
- CSV는 시트별 파일이 든 zip으로 받아집니다. 쿼리·페이지·국가·기기·날짜와 적용 필터가 들어 있습니다.
- 화면 내보내기는 1,000행까지입니다. 더 필요하면 API나 BigQuery 내보내기가 있습니다.
- 파일 경로만 에이전트에 알리고 내용은 붙이지 않습니다.
