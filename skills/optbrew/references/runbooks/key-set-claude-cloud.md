# Claude Code 클라우드에서 Google 키 넣기 (환경 변수)

## beginner

왜 필요한가: 클라우드 세션에는 내 컴퓨터의 키 파일이 없습니다. 대신 클라우드 환경 설정의 환경 변수 칸에 키를 넣어 두면, 그 환경에서 시작한 세션이 `OPTBREW_GOOGLE_API_KEY`라는 이름으로 읽습니다. 키는 이 설정 창에만 붙여 넣고 에이전트 대화창에는 붙이지 않습니다. 주의: 그 환경을 쓰는 사람은 누구나 환경 변수를 읽을 수 있습니다. 나만 쓰는 개인 환경에만 넣고, 조직이 공유하는 환경에는 넣지 않습니다.

1. 브라우저에서 claude.ai/code를 엽니다.
2. 새 세션 화면으로 갑니다. 이미 실행 중인 세션을 고치려면 위쪽 세션 제목 옆 화살표(caret)를 누르고 **Edit cloud environment**를 고른 뒤 5번으로 갑니다.
3. 메시지 입력 상자 바로 아래 줄에서 첫 번째 컨트롤(환경 이름이 적힌 버튼)을 누릅니다.
4. 목록의 **Cloud** 아래에서 내 개인 환경 줄에 마우스를 올리고, 줄 오른쪽에 나타나는 설정 아이콘(톱니바퀴)을 누릅니다. 환경이 안 보이면 **More** 줄을 먼저 누릅니다. 환경이 하나도 없으면 목록 맨 아래 **New environment**를 눌러 이름을 적고 **Add environment**를 누른 뒤, 만든 환경의 설정 아이콘을 누릅니다.
5. 설정 창에서 **Environment variables** 칸을 찾습니다.
6. 칸의 맨 아래 새 줄에 `OPTBREW_GOOGLE_API_KEY=`를 입력합니다. 등호 앞뒤에 공백을 넣지 않습니다.
7. 등호 바로 뒤에 복사해 둔 Google 키를 붙여 넣습니다. 따옴표는 붙이지 않습니다.
8. 줄 하나에 변수 하나만 있는지 확인합니다. 다른 변수가 이미 있으면 그 줄은 그대로 둡니다.
9. 창의 저장 버튼(**Save changes**)을 누릅니다. (화면 확인 필요: 저장 버튼 이름)
10. 새 세션을 시작하고 감사를 요청합니다. 설정은 새 세션에서 확실히 적용됩니다.
11. 에이전트가 "Google 키 있음"이라고 알려 주면 끝입니다. 키 값은 보이지 않는 것이 정상입니다.

키를 바꾸거나 지우려면 같은 창에서 그 줄을 고치거나 지우고 저장합니다. 한글 화면에서는 항목 이름이 번역되어 있을 수 있습니다. 위 영문 이름과 같은 자리의 항목을 고릅니다. (화면 확인 필요)

## brief

- claude.ai/code 새 세션 화면에서 메시지 상자 아래 첫 컨트롤 → 환경 행의 설정 아이콘 → **Environment variables**.
- `OPTBREW_GOOGLE_API_KEY=키` 한 줄(공백·따옴표 없음)을 넣고 저장합니다. `.env` 형식이며 `#`가 든 값은 따옴표로 감쌉니다.
- 환경 변수는 그 환경을 쓰는 모두가 읽을 수 있으므로 개인 환경에만 넣습니다. 새 세션에서 적용됩니다.
- 키를 대화창에 붙이지 않습니다.
